Cinder Yard — a round-based tactical FPS in three.js. 3v3 rounds in a dusk freight yard: plant the charge at Site A or Site B or wipe out WARDEN, earn money each round, spend it in the buy menu on four weapons, kevlar and a frag grenade, and fight bot squads that route through the map, hold angles, and react to what they see and hear. Gunfire rewards stopping to aim: recoil, spread and bloom punish firing on the move.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
